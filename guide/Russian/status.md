Статус CPU подтверждает работу загрузочного ядра и выполнение ARM64-кода. Для тача проверен ввод одним пальцем в Windows, включая края экрана. Изображение выводится через framebuffer. Кнопки пока работают только в UEFI.

Чтение и запись UFS проверены в Windows PE, включая стресс-тест на 256 МиБ. Проверка записи пока охватывает выделенную тестовую область; неограниченная запись и надёжная загрузка полноценной Windows ещё готовятся. Непроверенные пункты не означают наличие поддержки в Windows.
