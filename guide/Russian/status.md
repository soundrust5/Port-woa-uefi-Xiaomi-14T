Статус CPU подтверждает работу загрузочного ядра и выполнение ARM64-кода. По результатам на тестовом устройстве работают сенсорный ввод, мультитач и касания по краям экрана. Изображение выводится через framebuffer. Кнопки пока работают только в UEFI.

Windows PE загружается в ОЗУ из загрузочных файлов на UFS. Это подтверждает запуск WinPE с UFS; само по себе это ещё не подтверждает загрузку установленной Windows с системного раздела.

Чтение и запись UFS проверены в Windows PE, включая стресс-тест на 256 МиБ. Опубликованная проверка записи охватывает выделенную тестовую область. Установка полноценной Windows остаётся в разработке. Непроверенные пункты не означают наличие поддержки в Windows.
