В Windows проверены все восемь ядер CPU, динамическое изменение частот и boost. По результатам на тестовом устройстве работают сенсорный ввод, мультитач и касания по краям экрана. Изображение выводится через framebuffer.

Чтение и запись UFS проверены в Windows, включая стресс-тест памяти. Непроверенные пункты не означают наличие поддержки в Windows.

Считывание температуры и программное ограничение частот проверены; пороги пока консервативные. Длительная работа тепловой защиты ещё не проверена.

Android теперь загружается напрямую через штатный EFI stub, в том числе после проверенного теста RF/CONN, очистки и перезапуска. Инициализация A-die и независимое чтение RF-SPI подтвердили ID `66378A01`. Запуск прошивки Wi-Fi, подключение к сети и драйвер Wi-Fi для Windows ещё не готовы. В проверенной конфигурации Windows сохраняются восемь ядер, DVFS, 10,4 ГБ RAM, UFS, сенсорный ввод и обновление экрана по TE.
