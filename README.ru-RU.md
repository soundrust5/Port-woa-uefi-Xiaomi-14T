# UEFI и Windows на Xiaomi 14T

[English](README.md) | **Русский**

Экспериментальный порт UEFI и Windows on ARM для **Xiaomi 14T (`degas`)** на **MediaTek Dimensity 8300-Ultra (MT6897)**.

> [!IMPORTANT]
> **Установить Windows пока нельзя.** Порт находится в разработке. Публичной инструкции по установке и готового установочного выпуска пока нет.

## Текущий прогресс

**Windows запускается.** На тестовом телефоне Windows PE загружается до графического установщика Windows. Подтверждены работа процессора, вывод изображения, сенсорный ввод и доступ к UFS.

| Компонент | Статус | Подробности |
| --- | --- | --- |
| Загрузка Windows | ✅ Работает | Windows PE загружается и показывает графический установщик. Установка полноценной Windows готовится. |
| CPU | ✅ Работает | Работают выполнение ARM64-кода и загрузочное ядро. Поддержка всех ядер и управления питанием пока не подтверждена. |
| Дисплей | ✅ Работает | Вывод через framebuffer в UEFI и Windows, включая обновление анимации. |
| Сенсорный экран | ✅ Работает | В Windows проверены касания и правильные координаты, в том числе по краям экрана. Мультитач разрабатывается. |
| Накопитель UFS | ✅ Работает | Чтение и запись проверены в Windows PE, включая стресс-тест на 256 МиБ и чтение данных обратно. Поддержка загрузки полноценной Windows готовится. |
| Аппаратные кнопки | 🟡 Частично | Кнопки громкости и питания работают в UEFI. Поддержка кнопок в Windows пока не реализована. |

Статус отражает результаты на тестовом устройстве. Порт ещё не готов для повседневного использования. Остальные компоненты и ограничения перечислены на [странице статуса](guide/Russian/status.md).

## О проекте

Разработчик: [soundrust5](https://github.com/soundrust5).

Сейчас репозиторий содержит информацию о прогрессе и доступности проекта. Прошивка и пакеты драйверов будут описаны, когда будут готовы к публичному использованию.

Это независимый проект сообщества, не связанный с Xiaomi, MediaTek или Microsoft.
