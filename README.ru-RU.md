# Windows 11 ARM64 и UEFI на Xiaomi 14T

[English](README.md) | **Русский**

[![Latest UEFI](https://img.shields.io/github/v/release/soundrust5/Port-woa-uefi-Xiaomi-14T?include_prereleases&label=UEFI)](https://github.com/soundrust5/Port-woa-uefi-Xiaomi-14T/releases/latest)

Экспериментальный порт для **Xiaomi 14T (`degas`, MT6897)**. В Windows работают восемь ядер CPU, framebuffer-экран, мультитач и накопитель UFS.

> [!CAUTION]
> Если сомневаетесь или боитесь устанавливать UEFI, закройте этот репозиторий. Устанавливайте на свой риск. Порт ещё не закончен и может привести к неработоспособности телефона. Сначала сохраните данные; мы не несём ответственности за повреждённые устройства.
