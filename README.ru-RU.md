# Windows 11 ARM64 и UEFI на Xiaomi 14T

[English](README.md) | **Русский**

Экспериментальный порт Windows on ARM для **Xiaomi 14T (`degas`) — Dimensity 8300-Ultra / MT6897**.

На тестовом устройстве работают загрузка Windows с UFS, все восемь ядер CPU, framebuffer-экран, мультитач и чтение/запись UFS. DVFS пока не работает; ускорение GPU, Wi-Fi и Bluetooth не реализованы.

> [!CAUTION]
> Если вы сомневаетесь или боитесь устанавливать UEFI на свой телефон — смело закрывайте этот репозиторий. Мы не несём ответственности за повреждённые телефоны. Порт экспериментальный: в нём много ошибок и недоработок; установка может привести к неработоспособности устройства.
