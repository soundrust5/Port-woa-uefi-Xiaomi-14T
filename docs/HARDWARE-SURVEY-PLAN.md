# Обследование Xiaomi 14T

Для каждого устройства нужны адреса MMIO, прерывания, питание, тактирование,
сброс и последовательность запуска. Источники: live DT, sysfs, штатные драйверы
и журналы Android. Результаты сверяются с установленными бинарными модулями.

До аппаратного теста должны быть проверены разметка и резервная копия boot,
принадлежность используемой памяти, все записи MMIO и способ восстановления.
Адрес из DT сам по себе не означает, что регистр доступен при выключенном питании.
