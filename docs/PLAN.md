# План проекта

Рабочие компоненты перечислены в [статусе](../guide/Russian/status.md).

## Сделано

- Меню UEFI и загрузка Android/Windows.
- Восемь ядер CPU, управление частотами и температурные ограничения.
- UFS: загрузка системы, чтение и запись.
- Экран, мультитач и кнопки.
- WoA Helper для Android.
- Питание CONN/RF и чтение ID радиочасти Wi-Fi в UEFI.

## Следующие задачи

1. Запуск WLAN MCU, проверка ROM и загрузка прошивки Wi-Fi.
2. Обмен командами с Wi-Fi, затем драйвер Windows.
3. Bluetooth, USB, звук и остальные компоненты.
4. Сон и пробуждение после поддержки этих режимов в драйверах.
5. Дальнейшая оптимизация UFS и графики.

Изменения проверяются отдельно с сохранением рабочего образа и журналов.
