# Windows 11 ARM64 & UEFI on Xiaomi 14T

**English** | [Русский](README.ru-RU.md)

[![Latest UEFI](https://img.shields.io/github/v/release/soundrust5/Port-woa-uefi-Xiaomi-14T?include_prereleases&label=UEFI)](https://github.com/soundrust5/Port-woa-uefi-Xiaomi-14T/releases/latest)

Experimental port for **Xiaomi 14T (`degas`, MT6897)**. Windows boots with eight CPU cores, a framebuffer display, multitouch and UFS storage.

> [!CAUTION]
> If you are unsure or afraid to install UEFI, close this repository. Install at your own risk. This unfinished port can leave your phone unusable. Back up your data first; we are not responsible for damaged devices.
